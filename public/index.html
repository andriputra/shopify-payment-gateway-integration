Swipe invoice status (/InvStatus)

The public GET or POST /InvStatus endpoint requires the same secret as the server: Authorization: Bearer … (or the X-Inv-Status-Secret header, or a secret query/body field). That value is APP_SHARED_SECRET, PAYMENT_STATUS_API_SECRET, or INV_STATUS_API_SECRET — not the Shopify session token.

Uses fetch with Bearer — not the App Bridge session token.

Enter secret, shop, and invoice, then click Fetch.
